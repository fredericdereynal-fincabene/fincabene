📲 Compartir menú móvil con operarios

Cualquier operario puede escanear este código QR para tener el menú Fiera siempre disponible en su celular.

Para generar el QR, instalar la lib Python:
pip install qrcode

URL del menú :

https://fredericdereynal-fincabene.github.io/fincabene/menu.html
👁️ Ver menú

📌 Cómo configurar la URL antes de compartir

  1. Sube el dossier _Analisis a SharePoint, OneDrive o GitHub Pages.
  2. Obtén el enlace público de menu.html.
  3. Edita el archivo compartir_qr.html y reemplaza la URL si es necesario.
  4. Vuelve a ejecutar _RUN_SAISIE_TODO.bat para regenerar el QR.

📱 Android (Chrome)

Abrir el QR escaneado → tocar los 3 puntos → "Agregar a la pantalla de inicio" → Listo

🍎 iPhone (Safari)

Abrir el QR escaneado → botón Compartir ↑ → "Agregar a inicio" → Listo
